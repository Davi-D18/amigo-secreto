# Amigo Secreto
O projeto "Amigo Secreto" é uma aplicação web que permite adicionar nomes de amigos e sortear aleatoriamente um deles. A aplicação possui uma interface amigável e intuitiva, onde os usuários podem inserir nomes, visualizar a lista de amigos adicionados e realizar o sorteio de forma simples e rápida.

### Arquivos e Pastas

- `index.html`: Arquivo principal da aplicação, contendo a estrutura HTML.
- `src/assets/`: Pasta contendo os arquivos de imagem utilizados na aplicação.
- `src/css/style.css`: Arquivo de estilos CSS para a aplicação.
- `src/css/mediaQueries.css`: Arquivo CSS para aplicar media queries
- `src/js/app.js`: Arquivo JavaScript principal que gerencia os eventos e interações da aplicação.
- `src/js/functions.js`: Arquivo JavaScript contendo as funções principais da aplicação, como adicionar amigos, sortear amigo e exibir mensagens de erro.

## Funcionalidades

- **Adicionar Amigos**: Permite adicionar nomes de amigos à lista.
- **Sortear Amigo**: Realiza o sorteio aleatório de um amigo da lista.
- **Exibir Mensagens de Erro**: Exibe mensagens de erro caso o usuário tente adicionar um nome vazio ou duplicado.
- **Loading**: Exibe um ícone de carregamento durante o sorteio.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Como Executar o Projeto

1. Clone o repositório para o seu ambiente local.
2. Abra o arquivo `index.html` em um navegador web.
